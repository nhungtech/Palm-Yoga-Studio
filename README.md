# Palm Yoga Studio — App Quản Lý

App quản lý phòng tập yoga: lịch tập, ca tập, học viên, giáo viên, học phí, chi phí.

## Chạy thử trên máy

Chỉ cần mở trực tiếp file `index.html` bằng trình duyệt (Chrome/Edge/Safari...).

## Đăng lên Vercel

1. Push repo này lên GitHub (đã có sẵn `index.html`).
2. Vào https://vercel.com/new → Import repo này.
3. Framework Preset: chọn **Other**. Build Command và Output Directory: để trống.
4. Deploy.

## Lưu ý dữ liệu

App lưu dữ liệu bằng `localStorage` của trình duyệt — dữ liệu chỉ lưu trên từng máy/trình duyệt, không đồng bộ giữa các thiết bị khác nhau.
